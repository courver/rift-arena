一个在浏览器里玩的**英雄肉鸽竞技场**原型：选一个英雄，主武器自动开火，配合 Q / E / R 三个技能撑过 10 波敌人。每波结束可以**升级或更换**武器和技能。第 5、8、10 波是首领战，最终首领是三阶段的「裂隙之主」。

整个项目由我主导、用 AI 编程助手（Claude Code）从零完成，范围包括玩法设计、数值、代码、美术、音效和自动化平衡测试。没有用任何外部美术或音频素材：图形全部由代码生成，音效全部由 WebAudio 合成，可以公开展示。

## 玩法

| 操作 | 说明 |
|---|---|
| WASD / 方向键 | 移动 |
| 鼠标 | 瞄准 |
| 主武器 | **自动朝鼠标方向开火**；按 F 可关掉自动开火，改为按住左键射击 |
| Q / 空格 / 右键 | Q 技能（位移类） |
| E | E 技能（功能类） |
| R | 大招 |
| ESC / P | 暂停（查看属性、武器技能等级、构筑） |
| M | 静音（暂停菜单里可以分别开关音效、音乐、震屏） |

**手机**：横屏、竖屏都能玩（竖屏时场地变成竖长的 720×1280）。左侧按住拖动就是摇杆，自动瞄准最近的敌人并自动开火，右下角三个圆按钮放 Q / E / R，右上角是暂停。第一局会有操作提示。

**一局流程**：选英雄 → 清怪，每波结束回复 20% 生命并三选一（每局可重随 1 次）→ 第 5 波首领「熔核巨像」→ 第 7、9 波出精英 → 第 8 波首领「虚空织影」→ 第 10 波最终首领「裂隙之主」→ 结算（统计、最终构筑、最佳通关时间）。击败中途首领额外奖励一次强化。一局约 5–7 分钟。

### 英雄

两个英雄的初始配置和被动不同，武器和技能之后都可以换。

- **星弦 Lumen**（远程，生命 105）：星弹 / 相位闪 / 霜环 / 坠星。被动「星辉回响」：主武器每次命中，Q / E 冷却 -0.1 秒
- **赤刃 Kael**（近战，生命 155）：斩击 / 突进斩 / 旋风 / 血怒。被动「不屈战意」：生命低于 35% 时伤害 +40%、受伤 -15%

### 武器（6 种，各 5 级，自动开火）

| 武器 | 特点 | 升级路线 |
|---|---|---|
| 星弹 | 高速穿透弹 | 多射、穿透 |
| 斩击 | 近身扇形斩击，带击退 | 范围扩大、剑气 |
| 散射炮 | 近距离扇形弹丸 | 弹丸数、穿透 |
| 雷链 | 锁定准星附近的敌人并弹跳（范围伤害，无视盾牌） | 弹跳次数、攻速 |
| 回旋刃 | 飞出后折返，往返都能伤害 | 数量、体积 |
| 烈焰 | 持续喷火，附加灼烧 | 灼烧伤害、射程 |

### 技能（11 种，各 5 级）

- **Q（位移）**：相位闪（瞬移，Lv3 落点霜环）、突进斩（沿途伤害，Lv3 击杀刷新）、幻影步（留下吸引仇恨的分身，Lv3 分身爆炸）
- **E（功能）**：霜环（减速 / Lv3 冻结）、旋风（持续伤害，Lv3 吸怪）、引力井（在准星处吸住敌人）、哨戒炮台（自动射击）
- **R（大招）**：坠星（延迟陨石 + 流星雨）、血怒（攻速吸血爆发）、时间凝滞（冻结所有敌人和子弹）、天罚光束（跟随鼠标转向的贯穿光束）

### 强化卡

每次三选一，卡牌按颜色区分：

- **蓝色 · 升级**：当前武器或某个技能 +1 级，卡面写明这一级具体提升什么
- **紫色 · 更换**：换成另一把武器或同一栏位的另一个技能；新的保留原等级 -1，换装不会从零开始
- **灰色 · 属性**：12 种通用属性（伤害、攻速、暴击、吸血、冷却、范围、减伤……）

固定的出卡结构是一张升级、一张属性，第三张大多是更换。这样保证每次都有提升，同时不断出现新玩法可以尝试。

### 敌人（8 种 + Boss）

每种敌人都有自己的打法，第一次出现时左侧会弹出提示：

| 敌人 | 行为 | 应对 |
|---|---|---|
| 裂隙史莱姆 | 追击，死亡时分裂成两只小史莱姆 | 范围伤害清理 |
| 疾行者 | 停顿变红后高速突进 | 看到红色就横向走位 |
| 虚空射手 | 保持距离，瞄准线亮起后开火 | 躲开瞄准线 |
| 爆裂蜱 | 贴近后引爆；提前击杀会炸伤周围的敌人 | 在敌群里引爆它 |
| 盾卫 | 正面护盾挡下子弹（只造成 20% 伤害），转身很慢 | 绕后，或用范围、闪电 |
| 裂隙祭司 | 远离战场，周期性治疗附近的敌人 | 优先击杀 |
| 重甲蛮兵 | 红色预警线后冲锋 | 侧移躲开 |
| 精英守卫 | 冲锋 + 环形弹幕，并带随机词缀：迅捷 / 护盾 / 分裂 / 狂怒 | 看词缀调整打法 |

### 首领（3 个）

| 首领 | 波次 | 招式 | 应对 |
|---|---|---|---|
| 熔核巨像 | 5 | 连续砸地（地面红圈）、带一个缺口的震地环弹、落石雨；半血后更快、砸得更多 | 走出红圈，找环弹的缺口钻过去 |
| 虚空织影 | 8 | 瞬移后扇形弹幕、十字 / 六向光束（预警线）；半血后追踪法球 + 召唤射手 | 站在预警线之间，贴近它输出 |
| 裂隙之主 | 10 | 三阶段：环形弹幕 + 冲锋 → 螺旋弹幕 + 召唤 → 狂暴 | 躲冲锋线，清掉召唤物 |

击败首领时它的召唤物会一起消失。

### 美术

所有角色、敌人、首领、手持武器都用 Canvas 2D 在代码里画出来（渐变、贝塞尔曲线、发光），按 3 倍分辨率生成贴图再缩小显示，放大屏幕也清晰。画风是 Q 版 3/4 视角：角色朝向目标翻转，走路时跳动，武器握在手里指向准星，近战有挥砍动作、枪械有后坐，史莱姆会弹跳变形。

### 打击感与反馈

受击闪白、伤害数字（暴击放大变黄）、击退、屏幕震动、大招和击杀精英时的顿帧（hitstop）、死亡粒子、敌人出生预警圈、Boss 冲锋预警线、受伤红屏、残血条拖尾、技能冷却遮罩，以及程序合成的音效和背景音乐（菜单、战斗、首领战三种曲调）。

### 玩家反馈

结算页会显示死因，并请玩家用 5 档表情评分、勾选标签（太难 / 打击感好 / 看不懂……）。点「复制对局报告」就能把构筑、选卡顺序、死因、评分和设备信息一起复制下来，直接发给作者。这是"按玩家反馈迭代"的数据入口。

## 技术栈

- **TypeScript + Phaser 3.90**（只用了渲染、输入、补间、粒子和场景管理；移动、碰撞、AI 都是自己写的，没有用物理引擎）
- **Vite** 构建，`base: './'`，产物是纯静态文件
- **GitHub Actions** 自动部署：每次推送到 `main` 都会构建并发布到 GitHub Pages（`.github/workflows/deploy.yml`）
- 零外部素材：`BootScene` 用 Graphics 画出全部贴图，`sfx.ts` 用 WebAudio 振荡器和噪声合成全部音效

```
src/
  main.ts              游戏入口；?sim 模式的无头步进驱动
  config.ts            常量、URL 调试参数
  data/                纯数据：英雄、敌人、波次、属性强化
  game/
    Player.ts          玩家属性与状态
    Enemy.ts           敌人 AI（追击 / 风筝 / 蓄力冲锋 / 弹幕 / Boss 三阶段）
    weapons.ts         6 种武器（数据 + 开火逻辑，按等级取值）
    skills.ts          11 种技能和场上效果（炮台、分身、引力井、光束）
    cards.ts           强化卡：升级 / 更换 / 属性的生成和应用
    art.ts             所有角色和敌人的 Canvas 手绘形象
    fx.ts              反馈特效：粒子、伤害数字、预警圈、残影
    bot.ts             自动试玩机器人（势场寻路 + 躲预警 + 技能释放规则）
  lab.ts               平衡实验室页面（?lab）
  settings.ts          音效 / 音乐 / 震屏设置
  scenes/              Boot / Menu / Game / Upgrade / Pause / End
  ui/                  HUD、按钮、TouchControls（手机摇杆和技能按钮）
```

npm install
```

```

### 调试与平衡测试参数

| URL 参数 | 作用 |
|---|---|
| `?debug` | 显示 FPS 和敌人数；`N` 清场，`I` 无敌 |
| `?touch` | 在电脑上强制使用手机触控布局（鼠标拖动当摇杆） |
| `?portrait` | 在电脑上预览手机竖屏布局 |
| `?lab` | 平衡实验室：自动对战 + 实时图表 + 导出 CSV |
| `?bot` | 机器人自动操作英雄、自动选强化 |
| `?bot&speed=4` | 4 倍速 |
| `?bot&loop&sim` | **批量模拟**：脱离 requestAnimationFrame，用固定 60Hz 无头步进连续跑对局（不渲染），每局结果写入 `window.__runs` 和控制台 |
| `&hero=kael` | 只跑指定英雄 |

例：打开 `http://localhost:5173/?bot&loop&sim`，30 秒左右能跑完十几局，在控制台执行 `__runs` 查看每局的波次、胜负、死因和所选强化。

## AI 工作流

我负责方向、取舍和验收，AI 负责大部分实现。具体分工：

1. **立项**：AI 结合我喜欢的游戏类型（二游、MOBA / Deadlock）给出 3 个能在 1–2 天内做出核心循环的方案，我选了「英雄肉鸽竞技场 + 网页 Phaser」。
2. **设计到代码**：先让 AI 把设计拆成数据（英雄、敌人、波次、强化）和系统（AI、技能、反馈），数据和逻辑分离，方便后续调数值。
3. **自动化试玩**：AI 写了一个自动试玩机器人和无头模拟模式，可以批量跑对局，按胜率和死因调数值，不用每改一次都手动打一遍。
4. **迭代**：每轮记录在 [DEVLOG.md](DEVLOG.md)，包括改了什么、为什么改、AI 负责了哪些、遇到了什么问题。
5. **数据闭环**：机器人数据看平衡实验室，真人数据看结算页的对局报告，两者对比后再决定改哪里。

## 已知限制

- 托管在 GitHub Pages 上，国内部分网络访问较慢；微信内置浏览器会拦截，需要用系统浏览器打开
- 只有 2 个英雄、1 张地图；数值以机器人模拟为准，还需要更多真人反馈

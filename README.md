# 裂隙竞技场 · Rift Arena

一个在浏览器里玩的**英雄肉鸽竞技场**原型：选一个英雄，用 3 个技能加 1 个大招撑过 10 波敌人，每波结束三选一强化来组构筑，最后击败三阶段 Boss「裂隙之主」。

整个项目由我主导、用 AI 编程助手（Claude Code）从零完成，范围包括玩法设计、数值、代码、美术、音效和自动化平衡测试。没有用任何外部美术或音频素材：图形全部由代码生成，音效全部由 WebAudio 合成，可以公开展示。

## 玩法

| 操作 | 说明 |
|---|---|
| WASD / 方向键 | 移动 |
| 鼠标 | 瞄准 |
| 按住左键 | 普通攻击 |
| Q / 空格 / 右键 | 位移技能 |
| E | 范围技能 |
| R | 大招 |
| ESC / P | 暂停（可查看当前属性和构筑） |
| M | 静音 |

**一局流程**：选英雄 → 第 1–9 波清怪，每波结束回复 20% 生命，并从三张强化中选一张（每局可重随 1 次）→ 第 5、8、9 波出精英 → 第 10 波 Boss → 胜利 / 失败结算（统计数据、构筑、最佳通关时间）。一局约 4–6 分钟。

### 英雄

- **星弦 Lumen**（远程 · 控场）：星弹 / 相位闪（瞬移 + 无敌帧）/ 霜环（范围减速）/ 坠星（指定位置延迟陨石）
- **赤刃 Kael**（近战 · 斗士）：扇形斩击 / 突进斩（沿途伤害）/ 旋风（持续旋转）/ 血怒（震退 + 攻速、吸血、移速提升）

### 敌人

史莱姆（追击）、疾行者（快速脆皮）、虚空射手（保持距离、发射弹幕）、重甲蛮兵（蓄力冲锋，红色预警线）、精英守卫（冲锋 + 环形弹幕）、Boss（三阶段：环形弹幕 + 冲锋 → 螺旋弹幕 + 召唤 → 狂暴）。

### 强化（24 种）

12 种通用（伤害、攻速、暴击、吸血、冷却、范围、减伤……），每个英雄 6 种专属技能改造（如星弹穿透 / 分裂、霜环冻结、流星雨、剑气、突进击杀刷新、旋风吸怪）。卡牌分普通 / 稀有 / 史诗三种稀有度，按权重抽取，专属卡权重更高，让每局的构筑更有特色。

### 打击感与反馈

受击闪白、伤害数字（暴击放大变黄）、击退、屏幕震动、大招和击杀精英时的顿帧（hitstop）、死亡粒子、敌人出生预警圈、Boss 冲锋预警线、受伤红屏、残血条拖尾、技能冷却遮罩，以及程序合成的音效。

## 技术栈

- **TypeScript + Phaser 3.90**（只用了渲染、输入、补间、粒子和场景管理；移动、碰撞、AI 都是自己写的，没有用物理引擎）
- **Vite** 构建，`base: './'`，产物是纯静态文件，可以直接放到 GitHub Pages / itch.io
- 零外部素材：`BootScene` 用 Graphics 画出全部贴图，`sfx.ts` 用 WebAudio 振荡器和噪声合成全部音效

```
src/
  main.ts              游戏入口；?sim 模式的无头步进驱动
  config.ts            常量、URL 调试参数
  data/                纯数据：英雄、敌人、波次、强化（策划改数值只动这里）
  game/
    Player.ts          玩家属性与状态
    Enemy.ts           敌人 AI（追击 / 风筝 / 蓄力冲锋 / 弹幕 / Boss 三阶段）
    kits.ts            两个英雄的技能实现
    fx.ts              反馈特效：粒子、伤害数字、预警圈、残影
    bot.ts             自动试玩机器人（势场寻路 + 技能释放规则）
  scenes/              Boot / Menu / Game / Upgrade / Pause / End
  ui/                  HUD、按钮
```

## 本地运行

```bash
npm install
```

```bash
npm run dev
```

打开终端里显示的地址即可。生产构建用 `npm run build`，产物在 `dist/`。

> 注：本机全局的 npm 版本过旧（v2），实际用的是 Node 自带的 npm：`node "C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js" install`。

### 调试与平衡测试参数

| URL 参数 | 作用 |
|---|---|
| `?debug` | 显示 FPS 和敌人数；`N` 清场，`I` 无敌 |
| `?bot` | 机器人自动操作英雄、自动选强化 |
| `?bot&speed=4` | 4 倍速 |
| `?bot&loop&sim` | **批量模拟**：脱离 requestAnimationFrame，用固定 60Hz 无头步进连续跑对局（不渲染），每局结果写入 `window.__runs` 和控制台 |
| `&hero=kael` | 只跑指定英雄 |

例：打开 `http://localhost:5173/?bot&loop&sim`，30 秒左右能跑完十几局，在控制台执行 `__runs` 查看每局的波次、胜负、死因和所选强化。

## AI 工作流

我负责方向、取舍和验收，AI 负责大部分实现。具体分工：

1. **立项**：AI 结合我喜欢的游戏类型（二游、MOBA / Deadlock）给出 3 个能在 1–2 天内做出核心循环的方案，我选了「英雄肉鸽竞技场 + 网页 Phaser」。
2. **设计到代码**：先让 AI 把设计拆成数据（英雄、敌人、波次、强化）和系统（AI、技能、反馈），数据和逻辑分离，方便后续调数值。
3. **自动化试玩**：AI 写了一个自动试玩机器人和无头模拟模式，可以批量跑对局，按胜率和死因调数值，不用每改一次都手动打一遍。
4. **迭代**：每轮记录在 [DEVLOG.md](DEVLOG.md)，包括改了什么、为什么改、AI 负责了哪些、遇到了什么问题。

- 只有 2 个英雄、1 张地图；数值以机器人模拟为准，还需要更多真人反馈
